# 大学生求职信息管理系统 (Campus Job System)

这是一个基于纯 Java 开发的控制台应用程序，作为数据结构课程设计的综合实践项目。本系统实现了一个大学生求职信息管理平台，无需数据库支持，所有数据通过**对象序列化（Object Serialization）**持久化到本地 `.dat` 文件中，程序启动时自动加载，退出时自动保存。

## 🎯 项目亮点 (数据结构与算法实践)
本项目核心在于通过实际业务场景，深入应用多种数据结构与算法：
- **5种排序算法的实际应用**：
  - 用户按注册时间排序：**快速排序 (Quick Sort)**
  - 简历按期望薪资排序：**归并排序 (Merge Sort)**
  - 职位按薪资排序：**堆排序 (Heap Sort)**
  - 投递记录按时间排序：**插入排序 (Insertion Sort)**
  - 收藏记录按时间排序：**冒泡排序 (Bubble Sort)**
- **2种查找算法**：
  - 用户名/ID精确查找：**线性查找 (Linear Search)**
  - 简历按期望薪资查找：**二分查找 (Binary Search)**
- **集合框架的灵活运用**：熟练使用 `ArrayList`、`LinkedList`、`HashSet`（用于收藏去重）、`TreeSet`（用于投递记录排序）等。

## 🛠️ 技术栈与架构
- **开发语言**: Java (JDK 8+)
- **数据持久化**: 本地文件存储（Java IO / 对象序列化）
- **架构设计**: 采用经典的四层架构，职责清晰：
  - `model` 层：数据实体类定义（User, Resume, Job, Delivery, Favorite）
  - `storage` 层：底层文件读写，泛型接口 `FileStorage<T>` 实现代码复用
  - `service` 层：核心业务逻辑封装（用户管理、简历管理、职位管理等）
  - `menu` 层：控制台交互界面（主菜单、学生菜单、企业菜单、管理员菜单）

## ✨ 核心功能
系统支持三种角色（求职大学生、招聘企业、系统管理员），登录后展现不同菜单：

**👨‍🎓 求职大学生**
- 个人简历管理（创建、修改、按期望薪资排序与查找）
- 浏览与搜索职位（按薪资范围、按工作地点筛选）
- 投递简历、查看投递记录
- 收藏感兴趣职位、查看收藏列表
- 修改个人联系方式

**🏢 招聘企业**
- 发布新职位、查看已发布职位、下架职位
- 查看收到的简历投递、处理投递（标记查看、发起面试、拒绝）
- 修改企业信息

**🛡️ 系统管理员**
- 查看所有用户、按角色筛选用户
- 按注册时间排序查看用户（快速排序）
- 启用/禁用违规用户账号
- 查看所有职位、下架违规职位
- 查看系统统计信息（学生数、企业数、职位总数）

## 🚀 快速开始

### 1. 环境准备
- 确保本地已安装 JDK 8 或更高版本。
- 准备好 IDE（如 IntelliJ IDEA）。

### 2. 运行项目
1. 下载本仓库源码。
2. 使用 IDE 导入项目（普通的 Java 项目，无需 Maven 等额外配置）。
3. 找到 `menu.MainMenu` 类，运行其 `main` 方法。
4. 按控制台提示注册账号或使用默认测试账号（代码中内置了测试账号补全机制，运行时会自动生成 `hxl`, `ent123`, `admin2` 等测试数据）。
